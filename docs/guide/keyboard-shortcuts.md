# Keyboard shortcuts

## Command keys

Press a command key to **insert** that command at the selection; press <kbd>Shift</kbd> with the same key to **convert** the current selection to that command type.

| Key | Inserts | Shift+Key converts to |
| --- | --- | --- |
| `m` | `M` (moveto) | `M` |
| `l` | `L` (lineto) | `L` |
| `v` | `V` (vertical lineto) | `V` |
| `h` | `H` (horizontal lineto) | `H` |
| `c` | `C` (cubic bézier) | `C` |
| `s` | `S` (smooth cubic) | `S` |
| `q` | `Q` (quadratic bézier) | `Q` |
| `t` | `T` (smooth quadratic) | `T` |
| `a` | `A` (arc) | `A` |
| `z` | `Z` (closepath) | `Z` |

## Editing keys

| Key | Action |
| --- | --- |
| <kbd>Esc</kbd> | Cancel the current operation. |
| <kbd>Del</kbd> | Delete the current selection. |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Undo. |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Redo. |
| Hold <kbd>Ctrl</kbd> | Bypass grid snapping while dragging on the canvas. |
