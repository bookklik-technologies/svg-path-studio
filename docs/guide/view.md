# View, grid & viewBox

The **View** tab controls navigation, the drawing planes, and output tuning.

## Navigate

- **Fit path** — zoom so the whole path fills the viewport.
- **Zoom in / out / reset** — manual zoom control (also mouse wheel on the [canvas](/guide/canvas)).

## ViewBox

- **X / Y / Width / Height** — exact SVG `viewBox` fields.
- **Aspect lock** — keep the viewBox ratio while resizing.

## Grid & rulers

- **Snap** — toggle grid snapping (hold <kbd>Ctrl</kbd> on canvas to bypass).
- **Ticks** — ruler tick marks.
- **Numbers** — numeric ruler labels.

## Display

- **Preview** — render the path as a browser would.
- **Fill** — fill closed subpaths to visualise shape integrity.

## Panels

- **Commands sidebar** — show or hide the [command panel](/guide/insert#command-palette) sidebar.

## SVG output

Options for what lands in exported markup — see [Export & share](/guide/export-and-share):

- **Minify** — strip whitespace from the `d` string.
- **Precision** — rounding of coordinates written to the output.
